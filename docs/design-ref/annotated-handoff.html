INTERACTIES & GEDRAG

STAATSTRANSITIES, ANIMATIES EN GEBRUIKERSFLOWS
Zijpanelen — Open/Dicht
1
Gebruiker klikt ✕ op zoekpanel
State searchOpen = false
// Wrapper krijgt width: 0, kaart groeit mee .search-wrapper { width: 0; overflow: hidden; transition: width 320ms cubic-bezier(0.25,0.46,0.45,0.94); }
2
Zoek-knop verschijnt op de kaart (linksboven)
Animatie opacity: 0 → 1, pointer-events: none → auto, zelfde 320ms easing
3
Gebruiker klikt "Zoeken"-knop
State searchOpen = true — omgekeerde animatie: width 0 → 295px, knop fadt weg
Marker klik → Scanpanel openen
1
Gebruiker klikt op een kaartmarker met persoon
Event onMarkerClick(person) aangeroepen vanuit SVG <g>
// SVG marker — pointer-events: all (parent SVG is none) onClick={(e) => { e.stopPropagation(); if (m.person) onMarkerClick(m.person); }}
2
App updatet staat
State activePerson = person en scanOpen = true
const handleMarkerClick = (person) => { setActivePerson(person); setScanOpen(true); };
3
Scanpanel schuift open met persoonsdata
Animatie wrapper width 0 → 325px. Naam, beroep, adres en paginanummer worden direct getoond.
Kaart — Zoomen & Pannen
1
Slepen (pan)
Event mousedown / mousemove / mouseup op kaart-container
// Transformatie op de img transform: scale(zoom) translate(pan.x/zoom px, pan.y/zoom px) // Deling door zoom: compenseert scale zodat pan in schermcoördinaten blijft
2
Zoomen via knoppen
Stap ±0.4, bereik [1.0 – 6.0]. Reset: zoom 2.6, pan {x: -38, y: -42}
zoomIn: setZoom(z => Math.min(+(z + 0.4).toFixed(1), 6)) zoomOut: setZoom(z => Math.max(+(z - 0.4).toFixed(1), 1)) // transition: 0.15s ease-out — alleen wanneer niet aan het slepen
